# Screenshots

This folder stores manual screenshots, mockups, and visual QA captures for OrbiAgents.

Why this exists:

- keeps the repo root clean
- separates product assets from runtime code
- gives us one predictable place for UI references and before/after captures

Current contents include:

- dashboard screenshots
- login screenshots
- canvas/render test captures

If any screenshot later becomes part of the docs or README, link it from here instead of placing image files at the repo root.
