# OrbiAgents Desktop 0.4.6-orbi.1

## What's new

- The Munder-derived desktop is now the default OrbiAgents application.
- Original OrbiAgents workers animate across a licensed replacement office.
- Local builds keep automatic permissions, telemetry, and updates disabled by default.

## Requirements

This local QA build supports Apple silicon macOS. Public distribution requires signing and notarization.
